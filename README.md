# Dark Dome Archives

Site desenvolvido para uma atividade acadêmica de HTML.

## Sobre o projeto

O Dark Dome Archives é um site criado para apresentar informações sobre os jogos da empresa Dark Dome.

O projeto foi desenvolvido utilizando apenas HTML, sem CSS e JavaScript, seguindo as orientações da atividade.

## Conteúdo do site

O site possui páginas com:

- Página inicial
- Jogos da Dark Dome
- Informações sobre o projeto
- Imagens e descrições dos jogos
- Elementos multimídia

## Tecnologias utilizadas

- HTML5
